# Implementation plans

This folder holds implementation plans while the work they describe is in flight. A plan is
the ordered work for one part of the groups system. Once that work ships, its lasting content
moves into the design records, and the plan is deleted.

No plans are active. The design itself is in [Design](../design.md) and
[Decisions](../decisions.md).
