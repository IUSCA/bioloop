Notes — screen 2

  • The source list is scoped to the caller's groups, and GET /v2/fs resolves the typed path against that same scoped set. Scoping the list alone would leave the contents readable at a guessed path.
  • Name availability is checked against a scoped endpoint. It never reports that another group holds the name — only that this one may or may not use it.
  • No project or instrument fields. Both are global concepts today and would leak one group's records to another; attaching them after creation still works.
  • The folder row shows size and file count, which is what tells a user they picked the right run.

Notes — screen 4

  • The dialog is closed and the transfer continues. It runs from stores/v2/upload.js, so a route change does not touch it. This is a single-page application; navigating does not reload the document.
  • The legacy stepper blocks navigation with onBeforeRouteLeave and a browser confirm. That is a consequence of keeping every tus.Upload in component state, not a browser limit. A full page would have blocked exactly the same way.
  • The tray states the one real limit: a reload ends the transfer. A File handle cannot outlive the document, and storeFingerprintForResuming is off because large sessions exceeded the browser's storage quota. Saying so beats implying a resumability that is not there.
  • The list shows the dataset already, in an Uploading state. There is no separate uploads page — one filterable list, not two that can disagree.

Notes — screen 5

  • Replaces /datasets/uploads/:id. Upload state becomes a panel on the dataset's own page, so there is one place a dataset lives rather than two.
  • Reads GET /v2/datasets/:id/upload-log, which is authorized by the policy engine. The v1 read routes are RBAC-gated and a contributor is not an administrator.
  • The panel disappears once the dataset reaches its ready state. It is a transient surface, not a permanent tab.
  • Stage names describe outcomes, not internal task names.

Notes — screen 6

  • Every refusal names the thing that is missing and what would fix it. None of them falls back to a default group, a guessed source, or a generated name.
  • "That folder is already registered" does not say which dataset holds it or which group owns that dataset. The user learns only that this path is unavailable to them.
  • The last card carries the reasoning in the interface itself, because a user who knows a name is free elsewhere would otherwise read the refusal as a bug.

Notes — screen 7

  • Same modal as screen 1, opened from /v2/datasets instead of a group page. The only difference is that no group is implied, so the picker is shown rather than stated in the subtitle.
