About

Markdown

The Genomics Core Facility runs shared sequencing instruments and the analysis pipelines built around them. We register every run in Bioloop so that the raw reads, the assemblies, and the variant calls stay linked to the sample manifest they came from.

Working with us

Submit a project through the core intake form before sending material. We hold raw reads for 18 months and assemblies indefinitely. Datasets are owned by this group and shared with your lab group through a grant, so your lab keeps access after the project closes.

Instruments

  • Illumina NovaSeq X Plus — whole genome and exome, 25B flow cells
  • Oxford Nanopore PromethION 24 — long read and direct RNA
  • 10x Genomics Chromium X — single cell and spatial

How to cite this group

Genomics Core Facility (2026). Genomics Core Facility. Bioloop, Indiana University. https://bioloop.iu.edu/v2/groups/genomics-core

Acknowledge the facility in publications that use data produced here. Individual datasets carry their own citation.

The split rule. A field gets a typed column when a page header, a card, or a search query reads it on its own. A repeating list nobody filters on stays inside the existing metadata JSON. That puts four typed columns on group and three on collection, and leaves links, citations, and publications as JSON that the API validates on write.

Decision 1 — does the profile take the Overview tab?

The mockups say yes. About, citation, and publications fill the main column; the current definition list demotes to a Details card in the right rail, minus the rows a non-member has no business reading.

The alternative is a seventh tab named Profile, which keeps Overview as the admin panel it is today. Cheaper to build, and it puts the outward-facing page one click behind the internal one.

Decision 2 — may a viewer see what they cannot see?

The collection mockup shows 8 of 20 visible to you and a strip reading 12 more datasets are in this collection. Names, sizes, and contents stay hidden. Zenodo and dbGaP both publish that a restricted thing exists and gate the data itself.

The count is still a disclosure: it tells an outsider how large the collection is. Suppressing it costs the viewer any way to know a request is worth making.

What the platforms do

Zenodo communities
Name, short description, type, website, and one or more ROR organisations in the header; a logo; separate long-form about and curation policy pages. Record metadata is always public and only files are restricted.
Dataverse collections
Logo, tagline, and a URL behind the tagline, set under Theme and Widgets. A child collection inherits the parent's theme, which maps onto the group hierarchy already in the schema.
GitHub organisations, OSF
One markdown document is the organisation's front page, kept apart from the settings screens. This is the pattern the About card copies.
dbGaP, EGA
Study-level metadata is public and individual-level data needs an application. Citation is by accession plus a link to the study page, which is why the citation block sits on the profile rather than beside the data.
DataCite
Related publications are a first-class property, not prose. Store the DOI and the relation, and render Creator (Year). Title. Publisher. Identifier for people to read.
