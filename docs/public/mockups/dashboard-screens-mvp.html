One page, not three

The previous version of this mockup drew three disjoint dashboards. This one draws one page composed of sections, each rendered when the caller's persona and data warrant it. The personas are not disjoint people: a group admin files access requests and holds grants like anyone else, and the old group admin screen gave them no view of either.

Personal sections render for every persona. Governance sections render for a group admin and a platform admin. Platform sections render for a platform admin alone.

What the earlier mockup drew and this one does not

Each of these has no query behind it today. Drawing one means inventing a number, and a stat with nothing behind it is left out rather than filled with a placeholder.

DroppedWhy
Every delta — "↑ 2 since yesterday"Needs a time series nothing records.
Active grants count for my groupsCounting exists per resource only.
Aggregate member counts, direct and transitiveNo aggregate query. A group row shows its own member count instead.
Discover and request panelDataset search returns only rows the caller can already reach. Finding a dataset you do not have is unbuilt.
All pending requests, system-wideThe pending queue is scoped to the caller as reviewer. No route lists every open request.
Stale request alerts, over 7 daysNothing computes it.
Activity feed for a group adminThe audit route is platform admin only, by design.
Quick actions gridEvery action needs a target group, and each modal opens from a group page.
Compact group treeThe groups page already draws it. The dashboard links there.
"via AI Lab membership" on each reachable datasetCosts one coverage call per row. The dataset's Access tab answers it properly.

Visual conventions this follows

Gray neutrals rather than slate. One radius at 8px. Depth from a border and a background step, never a shadow or a gradient. Badges are tinted-transparent and uppercase, and each role keeps its fixed tone: amber for group admin, red for platform admin, emerald for oversight, sky for member, and indigo for transitive member. The hero is the one place the type scale goes above 20px.

Colour is never the only signal. An archived group carries a labelled badge, and an oversight row says "read-only" in words.
